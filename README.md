# One Letter: Coffee or Tea

**Entry: A — coffee.**

The bounty asks for a single letter: **A** for coffee, **B** for tea. This entry
picks coffee, because coffee wins on vividness. One letter has to carry the
whole answer, and coffee's cluster — the morning jolt, the ritual, the
intensity, the "don't talk to me before my coffee" energy — lands fuller and
more alive than tea's calm, cozy quiet. Coffee is also the funnier pick: the
addiction memes write themselves. So: **A**.

`main.ts` writes exactly that one byte, `A`, to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(no newline, no spaces).
